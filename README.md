# Marketing Data Analysis



This repository contains source files, scripts and resulting dashboards for a practice case using sample data provided by \[Ali Ahmad](https://github.com/aliahmad-1987/DataAnalystPortfolioProject\_PBI\_SQL\_Python\_MarketingAnalytics/blob/main/Episode%202%20-%20PortfolioProject\_MarketingAnalytics.bak).



The information was extracted from a SQL Express backup file using SQL queries to render 6 relevant tables as .csv files, then loaded into a DuckDB in-memory database to perform basic exploration and cleaning tasks.



Afterwards, one of the resulting tables was enriched with the NLTK python library to quantify user input into one-dimensional scores so they could be put in a graph, as part of the resulting dashboard.



Finally, the cleaned tables were loaded into Power BI, organized into a star schema, and used to compose three interactive dashboards that would enable stakeholders to provide value after observing and analyzing the obtained information.



\[Said dashboards can be found here](https://app.powerbi.com/view?r=eyJrIjoiNmM3NmIyYzctMWI1Ni00NjQ2LTk4MjUtNTI3NmU3YmM2YmE3IiwidCI6ImU5NWY3MzFmLTgyYzMtNDUwYy04MTIzLTE2ZTVmZWMyNzcxZCJ9).
